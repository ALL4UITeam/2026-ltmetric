# 2026-ltmetric

LTMetric 공식 웹사이트 프로젝트입니다.

## GitHub Pages

- 사이트 URL: https://all4uiteam.github.io/2026-ltmetric/
- `main` 브랜치에 push하면 GitHub Actions가 자동으로 배포합니다.

## 로컬 미리보기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 으로 확인합니다.
`npm run build`는 `dist`에 정적 파일을 만들고, `npm run preview`로 빌드 결과를 확인합니다.
